# Avancini OS

Ecossistema comercial da Avancini, formado por três experiências no mesmo projeto:

- `/` — Avancini OS, matriz e porta de entrada;
- `/dash` — Avancini Dash, sites e landing pages;
- `/sync` — Avancini Sync, chatbot e atendimento com IA.

As rotas Cora, Motora, Vértice e as demonstrações de clínica, estética, advocacia, salão e outros nichos são somente experiências de portfólio da Avancini Dash. Elas não são sistemas separados e não devem substituir a identidade principal.

## Desenvolvimento local

```bash
npm run dev
npm run build
```

O projeto usa Vinext, React e TypeScript. Não publique no Git, Vercel ou qualquer hospedagem sem autorização expressa do proprietário.
