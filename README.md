# Avancini Web

Site comercial da Avancini Web, unidade da Avancini OS especializada em landing pages, sites institucionais e e-commerces com foco em posicionamento e conversão.

## Destaques

- Vitrine rotativa com conceitos para diferentes segmentos
- Demonstrações ampliadas de landing page, site institucional e e-commerce
- Estruturas completas para loja de carros, moda, imobiliária e fast-food
- Projetos reais da Clínica San Diego e Tape Car
- Layout responsivo para celular, tablet e desktop
- Contato direto por WhatsApp

## Executar localmente

Requisitos: Node.js 22.13 ou superior e pnpm.

```bash
pnpm install
pnpm dev
```

Para validar a versão de produção:

```bash
pnpm exec vinext build
```

O projeto utiliza Next.js, React, TypeScript e vinext.
